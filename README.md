# 우리집 도트마을 (Dotorian village)

이웃들과 함께 사는 파스텔 동화풍 섬마을 게임. 폰 브라우저에서 바로 해요.

- 게임: https://maroseol0427.github.io/Dotorian-village/
- 관리자: https://maroseol0427.github.io/Dotorian-village/admin.html
- 서버: Firebase (구글 로그인 + Realtime Database). 관리자가 등록한 구글 계정만 들어올 수 있어요.
- `database.rules.json`: Firebase Realtime Database 규칙 (콘솔 → 규칙 탭에 붙여넣기)
